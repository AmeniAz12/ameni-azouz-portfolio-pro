OWASP Juice Shop Web Security Lab

Educational OWASP Top 10 A03:2021 - Injection case study showing an authentication bypass on OWASP Juice Shop in a local lab.

OWASP Top 10Juice ShopSQL Injection

Project objective

Show how unvalidated user input can be interpreted as SQL code, neutralize password verification and cause unauthorized access in OWASP Juice Shop.

Laboratory environment

Local lab with OWASP Juice Shop exposed at http://localhost:3000/#/login for a controlled demonstration.

  • Intentionally vulnerable OWASP Juice Shop application
  • Web browser used to interact with the login form
  • Educational scenario focused on A03:2021 - Injection
  • Short embedded video to replay the demonstration

Methodology

01

OWASP Top 10 context

The project targets A03:2021 - Injection, a major risk when user-controlled data reaches an interpreter directly.

02

Controlled payload

The email field receives the payload ' or 1=1-- to close the string, force a true condition and comment out the rest of the query.

03

Visual validation

The login attempt is performed in Juice Shop and the expected result is unauthorized access to the administrator account.

04

Remediation

Expected protections include prepared statements, input validation, least privilege and defensive monitoring.

Key findings

Observation

The email field accepts input that changes the expected SQL logic.

Interpretation

User data is not isolated from the query and becomes executable by the SQL interpreter.

Impact

An attacker can bypass authentication and access an account without knowing the password.

Risk and impact

A SQL injection can lead to authentication bypass, unauthorized account access, sensitive data exposure and data modification or deletion.

  • Authentication bypass
  • Unauthorized account access
  • Sensitive data exposure
  • Data modification or deletion

Recommendations

  • Use prepared and parameterized queries
  • Validate and filter user input according to the expected format
  • Apply least privilege to the database account
  • Monitor abnormal attempts from a defensive perspective
